Modul 1 — BHA & Rotary Steering

Bottom Hole Assembly, jenis rangkaian, dan sistem pengarah lubang.

1.1

Komponen BHA (dari bit ke permukaan)

Urutan dasar drill string: Bit → Stabiliser → Drill Collar → BHA (bagian tebal/berat) → Drill Pipe menuju permukaan. Pada BHA motor lengkap dari dasar ke atas: PDC Bit → PDM Sleeve Stabilizer → PDM (Mud Motor) → String Stabilizer → MWD Tool → LWD Tools → Drill Collar → Jar → Drill Collar → Heavy Weight Drill Pipe → Drill Pipe → Casing Shoe. MWD = Measurement While DrillingLWD = Logging While DrillingJar = alat pembebas jepitan
1.2

Tiga Rangkaian Rotary BHA

TujuanNama RangkaianPrinsip Kerja
Build (naikkan inklinasi)Fulcrum AssemblyNear-bit stabilizer dekat bit jadi pivot point; drill collar di atasnya melengkung akibat gravity sag, menghasilkan lateral bit force ke arah build.
Hold (pertahankan inklinasi)Packed-Hole AssemblyBeberapa stabilizer dipasang berdekatan agar BHA "kaku"/lurus mengikuti sumbu lubang — arah tetap stabil.
Drop (turunkan inklinasi)Pendulum AssemblyStabilizer diletakkan jauh dari bit; bagian bawah tanpa penyangga melengkung karena gravitasi (sag) sebelum point of tangency, mendorong bit ke arah drop.
1.3

Konfigurasi Dasar BHA

TipeKarakteristik
Dumb Iron Rotary BHABisa dikonfigurasi build/drop dalam rentang terbatas; hampir tidak ada kontrol walk tendency.
Motor BHASteerable, mampu hasilkan dogleg besar; slide drilling memakan waktu; ada batas kecepatan rotasi drill string.
Rotary Steerable System (RSS)Steerable sambil full rotation (mis. Geo-Pilot®, iCruise®); kapasitas dogleg terbatas; rentan hole enlargement; keandalan lebih rendah dari motor.

Modul 2 — Anti-Collision

Menghindari tabrakan antar sumur saat pengeboran berarah.

Persiapan (Preparation)

  • Tinjau well plan terbaru, verifikasi surface location & datum elevation (RKB/Air Gap, MSL, Ground Level).
  • Cek Ellipse of Uncertainty (EOU) — mencerminkan ketidakpastian posisi wellbore akibat error pengukuran.
  • Pilih Instrument Performance Model (IPM) yang tepat: NS-Gyro-MS, MWD+SC, atau MWD saja.
Lebih banyak koreksi survei (SC, IFR, MS, SAG) → semakin kecil uncertainty.

4 Metode Scanning

  • Horizontal Plane — cek apakah offset well menembus bidang datar horizontal dari titik current well.
  • Travelling Cylinder — bidang tegak lurus terhadap current well; bisa "melewatkan" titik tabrakan mendekati tegak lurus jika interpolasi terlalu besar.
  • Closest Approach (3D) — scan segala arah dari kedua sumur; dianggap paling aman dan paling umum dipakai.
  • Minimum Distance — mirip 3D tapi arah scan dibalik; tidak digunakan oleh Sperry.

Clearance Factor (CF)

CF = Jarak antar pusat ÷ (Jarak antar pusat − Jarak antar ellipsoid)
  • CF < 1.0 → sumur bersinggungan/beririsan → STOP & REVIEW risiko HSE.
  • 1.0 < CF < 2.0 → terlalu dekat, pastikan customer paham risiko, ikuti prosedur collision risk.
  • CF > 2.0 → aman, lanjutkan pengeboran (drill ahead).
  • Makin kecil CF, makin dekat kedua sumur. Radius casing bisa ditambahkan agar center-to-center distance lebih realistis.

Modul 3 — Torque & Drag, Hidraulika, dan Eksekusi Steering

Gesekan, buckling, hidraulika lumpur, serta cara mengarahkan sumur di lapangan.

Torque & Drag

  • Fungsi: evaluasi kelayakan profil sumur, tentukan spesifikasi pipa, posisi HWDP, dan evaluasi kondisi lubang via friction factor.
  • Friction factor: 0.15–0.22 (casing, halus) vs 0.2–0.4 (open hole, kasar).
  • Buckling 3 level: Sinusoidal (2D snaking) → Helical (3D coil) → Lock-up (WOB tidak sampai ke bit).
  • Buckling berkurang jika: inklinasi lebih besar, kekakuan (EI) lebih tinggi, berat linear lebih besar, clearance radial lebih kecil, gesekan dikurangi lubrikan, kualitas lubang lebih baik.

Hidraulika

  • Input: trajektori sumur, sifat lumpur tiap seksi, desain drill string & BHA (motor, MWD), batas tekanan pompa rig, tipe bit & TFA/jets.
  • Flow rate optimal ditentukan oleh: hidraulika bit, kecepatan annular untuk hole cleaning, batas tekanan sistem, dan rekomendasi motor handbook.

Sliding & Toolface

  • Sliding: drill string tidak berotasi (0 rpm), hanya bit yang berputar via motor — untuk mengubah arah (build/drop/turn).
  • Toolface: arah mata bor pengarah menghadap; Magnetic (MTF) dipakai saat inklinasi < 5° (referensi utara), Gravity (GTF) dipakai saat inklinasi > 5° (referensi highside, kanan/kiri).
  • Reactive torque: kecenderungan drill string berputar berlawanan arah bit akibat differential pressure — memengaruhi kestabilan toolface.
3.4

Survey & Menghitung Slide untuk Dogleg

3 Komponen Survey: Depth, Inclination (0°=vertikal, 90°=horizontal), Azimuth (arah horizontal terhadap utara).

Survei dianggap berhasil bila Gtotal (±0.003G), Bcalc (±300 nT), dan dip angle (±0.3°) berada dalam kriteria yang diterima.
Rumus panjang slide:
Slide Required = (DLS Diminta ÷ Motor Yield) × Course Length
Contoh dari materi: DLS diminta 2.5°/100ft, motor yield 4.88°/100ft, course length 100ft → Slide = (2.5/4.88) × 100 ≈ 51.2 ft.
